# Portofolio Ayu Nuraeni - SMKN 1 Kawali (RPL)

Website portofolio pribadi modern, responsif, dan interaktif yang dibuat khusus untuk **Ayu Nuraeni**, siswi jurusan **Rekayasa Perangkat Lunak (RPL)** di **SMKN 1 Kawali**.

---

## 🌟 Fitur Utama Website

1. **Desain Modern & Responsif**: Tampilan rapi dan nyaman dilihat di laptop, tablet, maupun layar smartphone Android/iOS.
2. **Mode Gelap / Terang (Dark & Light Mode)**: Pengunjung bisa beralih tema dengan satu klik tombol bulan/matahari di navigasi (tersimpan di *local storage*).
3. **Efek Ketik Otomatis (Typing Effect)**: Teks peran di bagian Hero bergerak dinamis secara bergantian.
4. **Filter Kategori Proyek**: Pengunjung dapat memfilter proyek berdasarkan kategori (*Aplikasi Web* atau *UI/UX & Landing Page*).
5. **Formulir Kontak Interaktif**: Dilengkapi validasi input dan pesan notifikasi sukses setelah mengirim pesan.
6. **Tombol "Kembali ke Atas" (Back to Top)**: Memudahkan navigasi saat menggulir halaman panjang.
7. **Bebas Ketergantungan Rumit (Standalone)**: Semua kode HTML, CSS, dan JavaScript berada dalam satu file `index.html` yang bisa langsung dijalankan tanpa perlu instalasi server.

---

## 🚀 Cara Menjalankan Portofolio

1. Buka folder `c:\portofolio ayu`.
2. Klik dua kali (double click) file **`index.html`**.
3. Website akan otomatis terbuka di browser favorit Anda (Google Chrome, Microsoft Edge, Mozilla Firefox, dll.).

## 🛠️ Panduan Kustomisasi

### 1. Mengganti dengan Foto Asli
Cari bagian `<!-- Hero Visual / Avatar -->` di `index.html` (sekitar baris 900-1000):
```html
<div class="avatar-illustration">
  <i class="fa-solid fa-user-astronaut"></i>
</div>
```
Ganti icon tersebut dengan tag `<img>` foto Anda:
```html
<img src="foto-ayu.jpg" alt="Ayu Nuraeni" style="width: 160px; height: 160px; border-radius: 50%; object-fit: cover;">
```
*(Pastikan file foto disimpan di folder yang sama)*.
